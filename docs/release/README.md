# FloatTabs Release Document Status

Files in this directory are immutable-style **historical release records/evidence** for the version/build they name.

A release record may accurately describe what shipped at that time, but it does not define current task scope or current architecture after later merges. For a current release decision use live GitHub release/commit/CI evidence and the mode-selected execution authority: FILE_CONTROL Task/Status before cutover or an approved selected Issue after cutover. A historic release record cannot authorize a new release.
