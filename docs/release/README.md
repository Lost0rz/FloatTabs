# FloatTabs Release Document Status

Files in this directory are immutable-style **historical release records/evidence** for the version/build they name.

A release record may accurately describe what shipped at that time, but it does not define current task scope or current architecture after later merges. For a current release decision use live GitHub release/commit/CI evidence; repository documents do not define task authorization. Generic release and delivery procedures belong to the installed Engineering Governance plugin. A historic release record cannot authorize a new release.
