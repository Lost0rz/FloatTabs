# FloatTabs Performance Document Status

Performance documents are historic measurements/protocols unless a currently authorized task explicitly adopts their bounded methods. `FloatTabs_Stage_5_Resource_Benchmark.md` was written for the former Hot/Warm/Cold model; its targets are **not** present lifecycle acceptance gates.

For current work read [documentation routing](../README.md), [architecture contract index](../architecture/README.md), current source/tests and an accepted bounded product contract. The Phase 8 [measurement feasibility report](../architecture/FloatTabs_Runtime_Lifecycle_Phase8_WP0_Measurement_Feasibility_Report_V1.md) shows that ordinary public APIs do not deterministically attribute all WebContent/GPU footprints to the host: do not turn Runtime count into an exact GiB budget. Any new benchmarking target requires accepted scope and fresh evidence; older V1 memory plans cannot silently authorize it.
